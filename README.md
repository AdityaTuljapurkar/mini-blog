Its My first Django Project 
Here are the steps to create a new Django project envornment  :
1>     # Create a virtual environment 
                ->python -m venv myenv 
2>    # Activate the virtual environment (macOS/Linux) 
                ->source myenv/bin/activate 
3 >    # create Django project 
                ->python -m django startproject myproject
3> If you are facing any errror check for the Django in the virtual env 
                ->pip show django
4>    # ceration of the new app
                ->cd myproject
                ->python manage.py startapp myapp
